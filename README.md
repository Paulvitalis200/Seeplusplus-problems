Leap Year Logic: Write a program that determines if a year is a leap year.

# Steps
1. Figure out leap year. A leap year has one extra day. (366) February in a leap year has 29 days.
2. If a year is divisible by 4, it is a leap year.
3. ASk user for input.
4. Check if input is number. If not, ask again
5. Check if input is divisible by 4
6. Return True
7. Ask user if they would like to check for another year.
8. Redo the process.

Improvement Ideas:
1. Normalize input value to lowercase
2. Check if a user just puts a space
