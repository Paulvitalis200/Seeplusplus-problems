## PROBLEM

Unit Converter: Create a program that converts Celsius to Fahrenheit and Kelvin.

## Steps
1. Ask user for input value
2. If user enters an invalid value e.g a value that is not a float or an integer, request user to enter the value again
3. Get current conversion values for changing celsius to fahrenheit and kelvin
4. Create function to convert
5. Output value to the terminal. 
6. Ask user if they would like to convert another value. If yes, go over the whole process again, if not, exit the application.

## Formulas
0° Celsius = 32 Fahrenheit
0° Celsius = 273.15 Kelvin

0° Celsius = 273.15 Kelvin
0°C + 273.15 = 273.15K

0 Celsius = 32 Fahrenheit
(0°C × 9/5) + 32 = 32°F
